OBRAVOZ - versión 1

Qué hace:
- Crea una ficha por obra.
- Dicta una visita desde Chrome en Android.
- Guarda el historial de cada obra en el propio dispositivo.
- No necesita Notion ni una cuenta de IA.
- Puede instalarse como aplicación web (PWA).

IMPORTANTE:
Esta versión guarda los datos en localStorage del navegador. Si borras los datos del navegador, puedes perderlos. Es una versión de prueba; antes de usarla como único registro de trabajo conviene añadir exportación/copia de seguridad.

Cómo probarla:
1. Sube estos archivos a una carpeta de tu dominio con HTTPS.
2. Abre la dirección en Chrome en Android.
3. Crea una obra con "+ Obra".
4. Pulsa "Nueva visita".
5. Pulsa "Empezar a dictar" y habla.
6. Guarda la visita.

Chrome en Android puede pedir permiso para usar el micrófono.

Siguiente mejora recomendada:
- Exportar/copiar las visitas.
- Editar visitas.
- Detectar automáticamente el nombre de la obra a partir del dictado.
- Guardar en una base de datos online para no depender del almacenamiento del teléfono.
- Convertir frases libres en campos más fiables mediante IA, si se desea.
